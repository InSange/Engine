# NuNuEngine 개발 로드맵
> 최종 수정: 2026-03-30

Steam 출시용 3D 1인칭 협동 액션 게임 (R.E.P.O. 스타일) MVP 제작을 위한 엔진 확장 계획.

| Phase | 내용 | 상태 |
|-------|------|------|

## Phase 1 — 3D 렌더링 기반 ✅

**목표:** FBX 모델을 씬뷰에서 카메라로 확인할 수 있는 상태

| 작업 | 내용 | 상태 | 커밋 |
|------|------|------|------|
| 1-1 | Assimp NuGet 통합 + Mesh3D 리소스 클래스 (FBX 로딩) | ✅ | `ff2ef73` |
| 1-2 | Mesh3DVS/PS.hlsl — WVP 변환 + diffuse 라이팅 | ✅ | `365be1b` |
| 1-3 | MeshRenderer 컴포넌트 + 씬뷰 render-to-texture | ✅ | `365be1b` |
| 1-4 | 에디터 카메라 FPS 네비게이션 (우클릭 + WASD) | ✅ | `7347a2a` |

**검증 결과**
- Barbarian.fbx 로딩 후 씬뷰 패널에 로우폴리 실루엣 렌더링 확인
- 우클릭 홀드로 시점 회전 (Yaw/Pitch), WASD/Q/E로 6-DOF 이동 확인

**미완료 (Phase 1 범위 외로 이월)**
- 텍스처 바인딩 (Albedo PNG → 셰이더): Phase 2 이후 추가 예정
- Depth Buffer (현재 DepthEnable=FALSE): 씬 복잡해지면 추가

## Phase 2 — 캐릭터 & 물리 ⬜

**목표:** FPS로 맵을 돌아다닐 수 있는 상태

| 작업 | 내용 | 상태 |
|------|------|------|
| 2-1 | CharacterController 컴포넌트 (WASD 이동 + 중력 + 점프) | ⬜ |
| 2-2 | AABB Collider3D + 바닥/벽 충돌 (레이캐스트) | ⬜ |
| 2-3 | KayKit Platformer Pack FBX 익스포트 + 스테이지 배치 | ⬜ |

**검증 기준**

## Phase 3 — 게임 핵심 시스템 ⬜

**목표:** 저주 시스템 + 스테이지 구조 동작

| 작업 | 내용 | 상태 |
|------|------|------|
| 3-1 | Health 컴포넌트 (HP / TakeDamage / Die / 리스폰) | ⬜ |
| 3-2 | CurseComponent (저주 목록 / AddCurse / TransferCurse) | ⬜ |
| 3-3 | CurseManager 싱글톤 (저주 풀 관리 / 스테이지별 배분) | ⬜ |
| 3-4 | StageManager (Safe Area / Danger Area / 상태 관리) | ⬜ |
| 3-5 | ItemSystem (ItemBox 스폰 타이머 / 클리어 보상 상자) | ⬜ |

**검증 기준**
- 저주 2개 받고 상대에게 위임 → 상대 저주 목록 +1 확인

## 엔진 기술 부채 (언젠가 해결)

| 항목 | 내용 | 우선순위 |
|------|------|---------|
| Depth Buffer | PSO에 DepthEnable=FALSE — 오브젝트 겹침 처리 없음 | 높음 |
| 텍스처 바인딩 | Albedo PNG 샘플링 미구현 — 현재 단색 diffuse | 높음 |
| 스켈레탈 애니메이션 | Assimp 본 데이터 파싱 미구현 | 중간 |
| 씬뷰 Resize | 창 크기 변경 시 scene RT 재생성 미구현 | 낮음 |
| ExcuteCommandList 오타 | 실제 함수명이 `Execute`가 아닌 `Excute` — 전체 참조 변경 필요 | 낮음 |
