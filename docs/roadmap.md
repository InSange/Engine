## Phase 1 — 3D 렌더링 기반 ✅

**목표:** FBX 모델을 씬뷰에서 카메라로 확인할 수 있는 상태

| 작업 | 내용 | 상태 | 커밋 |
|------|------|------|------|
| 1-1 | Assimp 통합 + Mesh3D 리소스 클래스 (FBX 로딩) | ✅ | `ff2ef73` |
| 1-2 | Mesh3DVS/PS.hlsl — WVP 변환 + diffuse 라이팅 | ✅ | `365be1b` |
| 1-3 | MeshRenderer 컴포넌트 + 씬뷰 render-to-texture | ✅ | `365be1b` |
| 1-4 | 에디터 카메라 FPS 네비게이션 (우클릭 + WASD) | ✅ | `7347a2a` |
| 1-5 | 알베도 텍스처 샘플링 + 깊이 버퍼 | ✅ | `f0bd5b7` |

**확인한 것**

- Barbarian.fbx 로딩 후 씬뷰 패널에 렌더링, 알베도 텍스처 적용
- 우클릭 홀드로 시점 회전(Yaw/Pitch), WASD/Q/E로 6-DOF 이동
- 깊이 버퍼(`D32_FLOAT`)로 오브젝트 겹침 처리

## Phase 3 — 게임 핵심 시스템 ✅

**목표:** 저주 시스템 + 스테이지 구조 동작

| 작업 | 내용 | 상태 | 커밋 |
|------|------|------|------|
| 3-1 | Health 컴포넌트 (HP / TakeDamage / Die / 리스폰) | ✅ | `90c28cf` |
| 3-2 | CurseComponent (저주 목록 / AddCurse / TransferCurse) | ✅ | `e610c48` |
| 3-3 | CurseManager (저주 풀 관리 / 스테이지별 배분) | ✅ | `58760ad` |
| 3-4 | StageManager (Safe Area / Danger Area / 상태 관리) | ✅ | `fd3d19f` |
| 3-5 | KarmaComponent + Game HUD | ✅ | `21ad2e8` |

**확인한 것**

- 저주를 받고 상대에게 위임하면 상대 저주 목록에 반영됨
- 저주 효과가 이동속도·받는 피해·조작 반전으로 실제 적용됨
- Curse / Stage / Karma 디버거 패널로 에디터에서 상태 확인

**계획과 달라진 점**

3-5는 원래 ItemSystem(ItemBox 스폰 타이머 / 클리어 보상 상자)이었으나,
저주 효과로 카르마를 적립하는 흐름이 먼저 필요해 KarmaComponent와 HUD를 먼저 붙였습니다.
ItemSystem은 Phase 5로 미뤘습니다.
